# Handbook — Personal Bilingual Reader

A private, browser-based reading workspace for your own copy of *The Handbook of Technical Analysis*.

## What it does
- Load your PDF directly from your device. The PDF is processed in your browser and is not uploaded to this repository or a server.
- Extract and display page text in English.
- Write or paste your Persian translation per page; translations are saved locally in this browser.
- Read English or Persian text aloud using the voices available in your browser/operating system.
- Navigate pages and search extracted English text.

## Run
Open `index.html` in a modern browser, or enable GitHub Pages for this private repository if your GitHub plan/settings support private Pages. The PDF itself is selected locally from your device.

## Notes
- This starter does not include the copyrighted book or a complete translation.
- Translation notes are stored in this browser's local storage. They are not synced between devices.
- PDF text extraction works best with text-based PDFs. Scanned pages may require OCR, which is not included yet.
- PDF.js is loaded from jsDelivr at runtime.
